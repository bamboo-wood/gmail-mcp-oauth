プライバシーポリシー

対象: Gmail MCP Kazuki Sasaki（以下「本アプリ」）

  1. 本アプリは、所有者本人が自分の Gmail アカウントを、自分のパソコン上の MCP サーバーから操作するためだけに使います。
  2. Google から取得するデータ（メール、ラベル、フィルタなど）は、所有者のパソコン上で処理します。所有者が使う AI アシスタントには、所有者の指示に応じて必要な範囲だけ渡します。
  3. 取得したデータを第三者に販売、共有、譲渡することはありません。広告にも使いません。
  4. 認証情報（アクセストークン、リフレッシュトークン）は所有者のパソコン上にだけ保存します。
  5. Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。
  6. アクセスをやめるときは、Google アカウントの権限設定から本アプリの許可を取り消せます。

Privacy Policy

This app is used only by its owner to access the owner's own Gmail account from a local MCP server. Data obtained from Google APIs is processed on the owner's computer, is never sold or shared with third parties, and is not used for advertising. Tokens are stored only on the owner's computer. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from Google Account permissions.
